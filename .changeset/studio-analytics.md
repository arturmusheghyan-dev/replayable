Add optional network-routed PostHog analytics alongside Studio-compatible structured parameters. The runtime provides declared custom events and the existing started, first-frame, first-interaction, completion and CTA events. Unconfigured networks use the disabled transport; delivery failures do not interrupt gameplay.

The Studio fork distributes versioned GitHub archives built from main. This changeset records source API intent and does not authorize upstream npm publication.
